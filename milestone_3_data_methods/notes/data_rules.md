# Data rules

Every data file in `data/` must satisfy the thirteen rules below. The rules are
checked by `tools/check_data.py`, which reports the number of violations of
each rule and exits with a non-zero status if any rule fails. The data are
generated by `tools/make_trials.py` (default seed 20261001, 4 blocks).

Symbols: *SOC* soil organic carbon (g/kg); *BD* bulk density (g/cm³);
*d* sampling depth, 0.20 m.

## Files

| File | Trial | Paper | Rows (4 blocks) |
|---|---|---|---|
| `data/sites.tsv` | site descriptions | all | 3 |
| `data/trials/t1_indicators.tsv` | soil health indicators, 3 systems | 1 | 36 |
| `data/trials/t2_nitrogen.tsv` | nitrogen rate, 5 rates | 2 | 60 |
| `data/trials/t3_intercrop.tsv` | maize–cowpea intercropping, 3 systems | 3 | 36 |
| `data/trials/t4_tillage.tsv` | tillage × residue, 4 combinations | 4 | 48 |
| `data/trials/t5_amendments.tsv` | organic amendments, 4 treatments | 5 | 48 |
| `data/trials/plot_register.tsv` | every plot of every trial | 6 | 228 |

## Rules

| ID | Rule | Exact condition |
|---|---|---|
| R1 | Sites | exactly 3 sites, `S1`, `S2`, `S3`; for each, clay + silt + sand = 100 % |
| R2 | Plot register | every `plot_id` is unique in `plot_register.tsv`; every row of every trial file has a `plot_id` that appears exactly once in the register with the same site, block and treatment; the register has exactly as many rows as the five trial files together |
| R3 | Complete blocks | in each trial, at each site, every block contains every treatment exactly once (randomised complete block design) |
| R4 | Soil pH | 4.5 ≤ `ph_water` ≤ 8.5 |
| R5 | Carbon and bulk density | 0 < every SOC value ≤ 60 g/kg; 1.00 ≤ every bulk density ≤ 1.70 g/cm³ |
| R6 | Indicator ranges | 5 ≤ `p_mehlich3_mgkg` ≤ 80; 5 ≤ `wsa_pct` ≤ 95; 20 ≤ `mbc_mgkg` ≤ 900 |
| R7 | Nitrogen response | 0 < `grain_yield_tha` ≤ 14; in every site and block, the yield of each fertilised plot ≥ the yield of the unfertilised (0 kg N/ha) plot of the same block |
| R8 | Nitrogen uptake | `n_uptake_kgha` ≥ 10 |
| R9 | Intercrop records | `SOLE_M` has a maize yield and cowpea `NA`; `SOLE_C` has maize `NA` and a cowpea yield; `INTER` has both; in every block the intercrop yield of each crop is below its sole-crop yield |
| R10 | Land equivalent ratio | in every site and block, 0.80 ≤ LER ≤ 1.60, where LER = maize(INTER)/maize(SOLE_M) + cowpea(INTER)/cowpea(SOLE_C) |
| R11 | Carbon added | `c_added_tha` = 0 for `CTRL`; equal (12.0 t C/ha) for every other amendment |
| R12 | Carbon retention and clay | the site mean of carbon retention over the three amendments increases with clay content (S2 < S1 < S3), where for each plot the stock change is ΔC = (SOC final − SOC initial) × BD × d × 10 (t C/ha) and retention = (ΔC − ΔC of the control in the same block) / carbon added |
| R13 | File format | UTF-8; LF line endings only; tab-separated; every row has as many fields as the header; no empty fields (`NA` is used only in `t3_intercrop.tsv`); the file ends with a newline |
