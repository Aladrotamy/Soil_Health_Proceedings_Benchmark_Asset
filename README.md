# Soil Health Proceedings — Overleaf / LaTeX Benchmark Asset

**Owner:** Rotimi Alade
**Domain:** Overleaf / LaTeX (academic authoring)
**Environment:** pdfLaTeX, biber, makeindex; Python 3 (standard library only) for the tools

## Overview

A 41-page conference proceedings volume, *Proceedings of the International
Symposium on Soil Health and Sustainable Crop Production, Volume 1*, edited by
Rotimi Alade. It contains six contributed papers, each with its own reference
list, abstract, introduction, methods (15 numbered equations), results,
discussion and conclusion, plus front matter, a List of Abbreviations and a
subject index.

The symposium is fictional and all trial data are **synthetic**, generated by a
seeded program. The 18 references are real published works, each verified
before use (see `SOURCES.md`). The results must not be read as evidence about
real soils or crops.

Every number in the volume is traceable: data files → `tools/compute_results.py`
→ `results/*.tsv` and `results/values.tex` → tables (pgfplotstable), figures
(pgfplots) and quoted values (`\res{key}`). Text, tables, figures and data
cannot disagree, and the 25 qualitative statements in the text are tested
against the data by `tools/check_claims.py`.

## Building the volume

```bash
cd golden_solution
pdflatex main && biber main && makeindex main && pdflatex main && pdflatex main
```

Each paper can also be typeset on its own from `papers/`
(`pdflatex paper3_intercropping`, `biber paper3_intercropping`, `pdflatex` ×2).

Tested toolchains: MiKTeX 26.5 (pdfTeX 4.27, biber 2.22) on Windows and
TeX Live 2023 (biber 2.19) on Linux, with identical results. Overleaf uses
TeX Live 2026 with pdfLaTeX. **Overleaf's free plan stops the compile with a
timeout** before a PDF is produced (0 errors reported up to that point),
because the five pgfplots figures and seven data-read tables need more than the
free plan's compile time; a full Overleaf compile needs an account with a
longer limit (see check C5.13 in `CHECKPOINTS.md`).

## Reproducing everything

```bash
python tools/make_trials.py                 # regenerate data (seed 20261001, 4 blocks)
python tools/check_data.py                  # 14 data rules -> 0 violations
python tools/compute_results.py             # regenerate results/ (values, tables, figures)
python tools/check_claims.py                # 25 of 25 text claims hold
python verifier/build_expected.py           # rebuild verifier/expected.json from golden_solution/
python verifier/verify.py project_source    # start state -> score 0.0000
python verifier/verify.py golden_solution   # golden solution -> score 1.0000
python verifier/run_oracle.py               # 21 of 21 oracle cases
python tools/make_variant.py --name variant_B --seed 118 --blocks 5
python tools/make_variant.py --name variant_C --layout letter12
python tools/make_manifest.py --check       # every file matches MANIFEST.sha256
```

All outputs use LF line endings and fixed decimal places, so they are
byte-identical on Windows and Linux; the fingerprints recorded in
`CHECKPOINTS.md` were confirmed on both.
